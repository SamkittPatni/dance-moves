# Dance Moves

## Project Description

This is a registry of all the **IDTA** and **BDC** syllabus steps for International Style Ballroom and Latin along with video clips for each step as well as lists of preceding and following figures.

This website was built using [Next.js](https://nextjs.org) and [TailwindCSS](https://tailwindcss.com/).

## Accessing the Website

The website can be accessed at https://samkittpatni.github.io/dance-moves/.

## Running Locally

The following provides a quick guide for running the project locally if you want to, say, fork the repository and make changes.

### Getting Started

First, clone/fork the repository:

```bash
git clone https://github.com/SamkittPatni/dance-moves.git
```

Then, install all the dependencies (ensure that you have Node.js installed):

```bash
npm install
```

### Running the Server

Run the development server from the root of the project:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the website.

### Making Changes

Any changes you make within the project will be auto-updated on the browser.
